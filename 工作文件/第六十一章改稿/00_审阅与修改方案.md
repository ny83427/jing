# 第六十一章《定额》审阅与修改方案

审阅对象：`正文/061-卷10-章61-定额.md` v0.2（2026-11-24）。正文约 5,100 字，平均每段 268 字，直接对话占 0.6%。

## 一、总评

这一章的骨架是好的。巡院重造僧籍，二十一个额，三十个人；三夜议论，老的出去要死，年轻的出去还能活；年轻人自己先去还俗，空出一个额"留以待来者"。这一章是第三部的开篇，把"晨课"立成第三部的一条线，又给第六十二章光正西去、第七十三章阿奴（萨摩安账上"六岁"那一行）都埋了伏笔，结构上不用大动。

问题全在写法上。这是第三部最典型的毛病：整章几乎都是转述，"他说……他说……他又说"，一段话动辄三四百字，人物没有一句是自己开口说的。三夜议论本是全章的戏，现在读起来像会议纪要；哈南在井台边那一场是全章最动人的地方，也被转述压平了。照"文风三强调"的标准，这一章要整体写成场面。

## 二、主要问题

### 1. 通篇转述，没有对话

能写成对话、该写成对话的地方，至少有这几处：

| 场面 | 现稿 | 改法 |
|---|---|---|
| 巡院小吏冷落景福 | 一句转述 | 写成三五句对话："你们那个写碑的老和尚呢？""故去了。""哦。" |
| 押衙送牒 | 转述 | 押衙开口，口气冷硬 |
| 灵宝数账上三十人 | 一大段名单 | 灵宝念，景福插话，名单里带出人 |
| 头一夜，景福说出去的该是老的；灵宝算账 | 两大段转述 | 两人来回辩，灵宝不急不躁，一笔一笔算给他听 |
| 第二夜安延 | 转述 | 安延说自己当年出去的事，景福拦他 |
| 巡院押衙"你去跟太宗说"、廊下沙弥 | 转述 | 对话 |
| 第三夜哈南在井台边 | 转述 | 全章核心，写足 |
| 光正带十个人来 | 一大段转述 | 光正说，史家大郎、罗家十二郎插话，景福追问，灵宝问空额 |
| 交名册 | 转述 | "空着做什么？""等人。" |
| 老曹与灵宝 | 转述 | 对话，保留"睡灶台上么" |

### 2. 段落过长

平均每段 268 字，有几段超过五百字。改时按场面分段，一个场面里叙述和对话交替。

### 3. 年龄错误

第二段"景福那年二十六，做主持做了一个多月"。第六十章写景福二十三岁接主持（元和十三年），本章开头是景净下葬后头一个七日，应是二十三、四岁。到长庆元年重造僧籍时，他才二十六。现稿把后一个岁数写到了前面，改为开头不写岁数，长庆元年那一节再写"景福二十六了，做主持做了两年多"。同段"执事要满二十五，师父故去那年他才二十三"不变。

### 4. 意象重复

- 章末"门外那盏灯昨夜是景福点的，还亮着，火苗缩成豆子大"，第六十章已经用了两回（景福第七天早上、景净临终那夜），这里第三回，删掉。章末只留四十一个人、光正在最后一排、木板上写"留"。
- 光正临走蹲在石墩前看"那一圈被油浸黑的印子"，是本章自己的意象，保留。

### 5. 小处

- "灵宝听完，没有夸他，点了点头"，删掉"点了点头"。
- "不是 A，是 B"现有四处，改后只留一处。
- 第二段末"师父挑中他，没有挑中他的才干，挑中的是他这张谁都不嫌的脸"，是叙述者替景福下的断语。改为景福自己在巡院廊下想到，口气放软："师父挑他，大概不是看他有多大本事。"

## 三、修改方案

结构不动，十二节照原次序走，逐节写成场面。篇幅估计在 6,000–6,500 字之间，比现稿长一些，长出来的是对话，不添情节。

1. **头一个七日的晨课（承第六十章）：**
   - 景福以为只有自己，回头看见灵宝、思圆、安延，再往后黑黢黢一片，天发灰时数出四十一个。
   - 新添散了以后一问一答："灵宝叔，你们怎么都来了？""你师父没叫我们来，也没叫我们别来。"
   - 删"景福说不清这是为什么，灵宝也没有说"。
2. **景福做主持：**
   - 写成巡院递状子一场，小吏不让坐，问"你们那个写碑的老和尚呢"。
   - 叙利亚话跟不上、不能掰饼、长安没有人能按手，压成景福在廊下等候时心里过的几句，不再一条一条叙述。
3. **长庆元年送牒：** 元和十五年宪宗暴崩压成两句。押衙进门交牒，三四句话交代"额内免课役、额外还俗附籍、十日为期、多一个主持连坐"。
4. **二十一与三十：**
   - 贞观诏、一百八十年没改的额，压成一小段。
   - 灵宝抱账簿来，念人数，景福插问。哈南、老曹、光正、史家兄弟、萨朗在名单里各带一句，读者先认得他们。
   - 收在景福一句"三十个，报二十一个，要出去九个"，灵宝"十日的期限，今天已经去了一日"。
5. **头一夜：** 景福说老的出去、寺里照样养；灵宝不驳，先叫他算账，算到"老的出去，回不来"。景福问"年轻的出去了，还回不回来"，灵宝答"这个我不知道"。
6. **第二夜：** 安延说城南草棚十几年、冻掉的半个脚趾、"我是叫人领回来的"，要自己先出去；景福拦："执事出去，坊里的人要说寺里连执事都养不起了。"
7. **巡院：** 景福去求"寄住"，押衙"二十一就是二十一，你嫌少，你去跟太宗说"；廊下沙弥说庄子上搭棚子；回寺灵宝一句"开远门外那块地，是埋人的"。
8. **第三夜，井台（写足）：**
   - 哈南摸门框、拿脚尖探路，摸到那块凸起的石头。
   - 哈南说叙利亚话，景福用他那半通不通的叙利亚话答，有几个词说不上来，就用唐话补。景福叙利亚话差这一层，在这里落成一场戏，不再靠叙述交代。
   - 哈南"出去"两个字听得懂，求景福把他领到开远门外的木桩边上，"坐一坐，就去见他们了"。
   - 景福扶他回屋，拿他的手去摸壶。回小屋后，两人坐到三更，都不提哈南，保留。
9. **第四天，光正：**
   - 光正说十个人自己去了巡院。景福红着脸："谁叫你们去的？"
   - 光正说窗下听了灵宝叔那笔账；史家二郎夜里哭，他哥哥说"咱们没有家，西市有的是库房"；罗家十二郎插一句"我娘巴不得"。
   - 光正说"名字在不在册上，阿罗诃认得我们"。
   - 灵宝问空着的一个留给谁，光正答"等一个能按手的人从西边来"。这一句给第六十二章光正自己西去伏笔，原意不变。
10. **交名册：** 押衙"空着做什么？""等人。"押衙不问等什么人，画押。
11. **搬出去：**
    - 罗家十二郎的娘"他敢不来，我打他"、萨朗空手去回鹘货栈护货、光正扫铺位后蹲看石墩油印，都写成短场面，各有一两句话。
    - 老曹与灵宝"你去了睡哪里，睡灶台上么"写成对话，收在老曹劈柴劈得更响。
12. **夜里收账簿：** 基本保留，是灵宝一个人的叙述段，不必硬加对话。只把长句理顺，"六岁"那一行与哥哥倒粥的回忆保留，结尾小字"额二十一，见在二十，余一，留以待来者"不动。
13. **章末晨课：** 四十一个，一个没少，光正在最后一排靠着门；景福在木板上写"留"。删去豆子火苗。

# 序章《出土》审阅意见与修改方案

审阅对象：`正文/000-序章-出土.md` v0.2（2026-11-07）。约 4,550 字，直接对话占 1.8%。

## 一、总评

序章的材料很好：工匠一镢头碰上石边，碑额九个字，莲花托十字，李之藻、曾德昭两个明末人物，伏尔泰说是假碑。可是现在这一章读起来像一篇碑的接受史。前三分之一是故事，后三分之二是讲解；结尾又用"那就由我来说一说"把读者交给一个说书人。

这一章能抓住读者的，是一个谜：**这块碑是谁、为什么、这样小心地埋下去的？** 现稿碰到了这个谜（"谁吃饱了撑的，拿麻布裹一块碑埋到地底下"），一句就放过去了，后面再也没有回到它。第三部第七十五章正写了埋碑那一夜，序章正好是那一夜留在地里的痕迹，两头可以对上。

## 二、主要问题

### 1. 钩子没有立住

- 出土一节写到"是一块碑"就转去知府和碑文，地里那些"人放进去"的痕迹，只有一撮烂布。
- 读者看完序章，记得的是"西洋传教士怎么看这块碑"，不是"碑底下有过什么人"。
- 第一章从天宝十五载灵州写起，序章结尾却没有一样东西把读者往前送，只有叙述者一句宣告。

### 2. 与第七十五章（作者审定 v0.6）对不上的地方

| 序章现稿 | 第七十五章 | 改法 |
|---|---|---|
| 碑面糊着烂麻布，"裹上三层麻布" | 何四娘抱来两床毡子（成亲那年铺的，已灰），阿依、小满从碑头往碑脚铺；碑底下是沙 | 改为两层烂毡，毡下有一层沙 |
| 只写碑身，曾德昭看时碑下"垫着一只石龟" | 碑座随埋，放在碑脚一头；座东南角缺一块，景福把经柜里那块碎石嵌回去，碴口上有锤子砸的白印 | 出土时挖出碑座；匠人发现一角是后嵌的石头，碴口有旧锤印；删石龟（第七十五章附注已说今龟趺是否原座不详） |
| 只说"正面朝上" | 碑往后倒，字朝上，碑头在北，碑脚在南 | 保留朝上，加碑头朝北一句，由匠人量地基时看出 |
| "比人还深的土坑" | 坑挖在碑后，碑近一丈 | 可留，改由匠人说"四尺来深就碰上了"，前后统一 |

### 3. 违反全书文风规矩

- **说书人口吻：** "那就由我来说一说。我们的故事，要从……说起"，违反 2026-11-23 所定"不用说书人口吻"。
- **只叙不议：** "这一切，碑都不知道……它什么也不说""碑上写不下"一整节，以及"曾德昭没有看出来的东西"一节讲以弗所会议，都是叙述者在评说、讲课。
- **叙述者泄底：** "又有人在六十多年以后，看着它裹上三层麻布，躺进了一个比人还深的土坑里"，把第三部埋碑提前点破，等于把谜底先交了。
- **口头禅：** "一会儿"五处，"很久"三处，"看了一眼"一处，"摇了摇头"两处。
- **对话：** 出土一场有匠人、东家、邻居、老和尚、老匠人，本是全书最适合写热闹群戏的地方，现在几乎全是转述。

### 4. 人物太多，哪一个都没站住

张赓虞、李之藻、金尼阁、曾德昭、邓玉函、阳玛诺、基歇尔、伏尔泰，一共八个名字。对基督教文史读者，这些名字有吸引力；可是一章里排开八个，个个只露一面，就成了名录。

现稿里真正写成人物的只有曾德昭，而且他身上已经有全书最好的一个对位：他先叫谢务禄，南京教案被押出国门，换了名字又进来，"名字换了，人还是这个人"。这句话跟第四十六章约南摘匾那句"又换了一个名字，人还是这些人"正好对上；碑上伊斯也是两个名字（唐名伊斯，叙利亚名耶兹德卜兹）。现稿没有用这条线收章。

### 5. 史实小订

- 邓玉函 1629 年在北京读出碑侧叙利亚文，私下传给会中，可用；但不宜写成当时就断定碑上的"耶兹德卜兹"就是汉文里的"僧伊斯"。这一层留给曾德昭自己去猜，不下断语。
- 出土地点有西安城西、盩厔两说，年份有天启三年、五年两说。正文照用天启三年、西安城西，附注里把两说并列。书中盩厔有景众（第三十九、七十一章），附注可顺带一提。
- 伏尔泰的话现稿写成转述大意，可留在附注，不必进正文。

## 三、修改方案

### 总的想法

序章只写两场，都写成场面：**地里的谜**，**碑上的名字**。传教士的接受史压成一条线穿过去，以弗所会议、阳玛诺、基歇尔、伏尔泰都移到附注（后记已有余地，也可放进后记）。不立说书人，章末停在一个动作上，第一章直接接天宝十五载灵州。

篇幅大致不变，4,000–5,000 字。

### 第一场　天启三年春，城西（约 2,200 字）

1. **开头接地气：** 仍从"一户人家要起房子"起，崇仁寺、地底下的碎砖瓦当一段保留，压短。
2. **碰上石边：** 写成匠人师徒、东家的对话，有来有往（骂一句"又是哪朝的破砖"、东家心疼工钱、徒弟要偷懒）。
3. **起出来以后，众人七嘴八舌：** 古墓盖子、石槽、王府旧物，各有各的说法，写出口气来。
4. **老匠人看出"人放的"**，三样痕迹，一样一样看出来：
   - 碑底下垫着一层沙，四面是黄土，"沙是挑进来的"；
   - 碑面上两层烂透的毡子，"不是麻，是毡，人家铺炕的"，从碑头往碑脚抹平过；
   - 碑脚那一头另埋着碑座，座的一角是一块拳头大的石头嵌进去的，碴口对碴口，碴口上还有一道发白的旧锤印。

   老匠人只说他看得出的："这碑不是倒下的，是放下去的。放它的人，怕它磕着。"旁人问谁放的，为什么放，他答不上来。谜就停在这里。
5. **碑额九字与莲花十字：** 认字的人念出碑名，老和尚挤上来看"不是我们佛门的"。十字只写一回，后面曾德昭那一场不再细描。
6. **知府** 一段压成三四句（移入崇仁寺、拓几份）。"七百七十多年"一句保留。

### 第二场　崇祯元年前后，崇仁寺（约 2,000 字）

1. **李之藻** 压成一段，从曾德昭心里带出：拓片在杭州李家传开，南京教案时人家骂"古来未有，来路不明"，李之藻写《读景教碑书后》说贞观年间就有了。张赓虞、金尼阁各一句。
2. **曾德昭到碑前：** 写他的两个名字（谢务禄、木笼、澳门、换名再进来）；他照着碑读"三一妙身""室女诞圣"，用拉丁话低声念，画十字；跟寺里的和尚有几句对话（和尚问他念的什么，他答不上来，或者答得驴唇不对马嘴）。删"自家祖先的坟"那段心理议论，改由动作带出来。
3. **描叙利亚字：** 他照样子把碑侧的字描下来，寄往北京。
4. **邓玉函回信（书信转报）：** 曾德昭在西安客寓灯下读信，信里三件事：
   - 碑侧是一串叙利亚人的名字，头衔是主教、乡主教、司铎；
   - 碑脚写着立碑那年在位的牧首名叫"宁恕"，"这位牧首，不在罗马"——以弗所、聂斯托利不讲课，只此一句，曾德昭读到这里放下信；
   - 有一行写的是"米利斯之子耶兹德卜兹，司铎，乡主教，吐火罗缚喝城人，立此石"。
5. **收章：** 第二天曾德昭再去碑前，在汉文里找到施主名下那个"僧伊斯"，又绕到碑侧找那行叙利亚字，两处他都伸手摸过。他想起自己先叫谢务禄，后叫曾德昭，"名字换了，人还是这个人"。章末停在他站在碑前的一个动作上（比如手按在那行字上，或者把描下的纸叠起来揣进怀里），不加叙述者的话。

   这样读者带着两个问题进第一章：碑是谁那样小心埋下去的；这个缚喝来的耶兹德卜兹、唐人叫伊斯的人，是谁。第一章写"胡僧"，第二章末"唐人叫我伊斯"，正好接上。

### 删、移

- 删"那就由我来说一说"及以下两段、"这一切，崇仁寺里的那块碑都不知道"一节、"六十多年以后……三层麻布"一句。
- 以弗所会议、阳玛诺《唐景教碑颂正诠》、基歇尔《中国图说》、伏尔泰"耶稣会伪造"之说，移入章末附注（附注网页不显示，只在 md 里）。后记若要谈接受史，可从附注取材。
- 删"石龟"。

## 四、请作者定

1. **李之藻那一段**：压成一段由曾德昭带出（推荐），还是保留成单独一场？
2. **"异端"这一层**：只用邓玉函信里"这位牧首，不在罗马"一句点到（推荐），还是保留现稿那样由叙述者交代以弗所会议？对基督教文史读者，这一层是兴趣所在；但交代多了，序章就成了讲义。
3. **伏尔泰**：移附注（推荐），还是正文留一两句？
4. **收章**：停在曾德昭摸着"僧伊斯"和"耶兹德卜兹"两处名字（推荐），还是保留现稿结尾"范阳的鼙鼓响了"的时间交代？

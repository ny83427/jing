## 二、史料能撑住什么，哪些是小说

| 事项 | 依据 | 本章怎样用 |
|---|---|---|
| 吕秀岩其人 | 碑末署衔"朝议郎前行台州司士参军吕秀岩书"，此外无可靠唐代传记、墓志、交游记录；生卒、籍贯、家世不详。朝议郎为正六品上文散官；司士参军掌津梁、舟车、舍宅、百工众艺之事（《唐六典》） | 写成罢官后在长安卖字的书手、五十来岁（第四十九章原已如此写）。家世、亲人、风骨的事例全是小说 |
| 吕书的风格 | 朱东华：得二王、《集王圣教序》一路，兼欧、虞、褚法度，带盛唐雄健；孙承泽称"秀逸遒劲"；李之藻称"字体遒媚不俗" | 只借来写他的字"清健、不飘"，不写成名家 |
| 徐浩与不空 | 《不空和尚碑》严郢撰、徐浩书，建中二年（781）立于大兴善寺；徐浩、颜真卿同参与过《多宝塔碑》 | 寺里听说大兴善寺已请徐公为不空三藏书碑，自己不去求。这是寺里的顾虑，不写成徐浩一定拒绝 |
| 不空的名位 | 705–774；历玄、肃、代三朝灌顶国师；永泰元年（765）制授特进、试鸿胪卿，加号大广智三藏；大历九年加开府仪同三司、封肃国公，卒赠司空；永泰元年仆固怀恩引吐蕃入寇时，主持新译《仁王经》与护国法会 | 与伊斯对照：伊斯是金紫光禄大夫（正三品散官）、试殿中监；不空是特进（正二品），后来开府仪同三司（从一品）、国公。同是胡僧，名位高出一大截 |
| 颜真卿 | 建中元年（780）撰书《颜氏家庙碑》，立于敦化坊家庙；德宗即位后任吏部尚书，同年改太子少师。与郭子仪有旧：广德二年（764）撰书《郭氏家庙碑》，其弟颜允臧曾为郭子仪判官 | 郭府一张帖子引见，颜读稿后婉拒、转荐吕秀岩，全是小说。拒绝的理由写成对碑中教义不熟、不肯以名字作保，不写成排斥景教 |
| 伊斯收葬香积寺死者 | 碑文"死者葬而安之"；本书第二十一章已写伊斯、段老七与城南老汉收葬香积寺战场两军尸首，"分得出来的分开埋，分不出来的埋在一处"；常乐坊有个后生天天来找被抓进叛军的阿兄，找了半个月没找到 | 吕秀岩的亲人就死在这一片里。常乐坊那个后生就是吕家的人（见第四节） |
| 陷贼者的处境 | 至德二载收复两京后，朝廷议处陷贼官，分等定罪（待核原文与月份） | 用来落实吕秀岩当年"不敢去"：他正在守选求官，家里有人从贼，怕被牵连 |

## 三、人物

- **伊斯**：五十五岁，金紫光禄大夫、试殿中监。这一章少说话，把求人这件事做到底：去郭府，去颜府，去崇贤坊。
- **景净**：三十四五岁，牧首信上的"众僧之父"，这一章他定下每日午时为碑祷告。
- **萨摩安**：守规监护，管账，主张碑晚立一年；不信祷告能顶账，但每天也到。
- **裴官人**：六十多，致仕在家，替寺里打听书手的行情、开名单。
- **郭子仪**：尚父，罢兵权之后，已开始远着伊斯（第五十章才写明）。这一章不露面，只给一张盖印的帖子，由老亲兵侯思远带出来。
- **颜真卿**：七十二岁，刚立了家庙碑。敬重伊斯，读稿极细，婉拒得郑重。
- **吕秀岩**：五十来岁，崇贤坊，屋小，案大，墙上一排笔。有骨头，也有过一次怯懦，这一章他把那一次说出来。
- **不空**：已死七年，只在伊斯的回忆里出现。

## 四、吕家的旧事（小说设定，需作者定）

- 吕家兄弟三人，原住常乐坊。至德元载叛军陷长安，老二被括进叛军。
- 收复长安时，吕秀岩二十八九岁，正在守选候官，朝廷在分等处置陷贼的人，他怕"家有从贼"四个字落到自己身上，没有去城南。
- 老三去了。第二十一章那个常乐坊的后生（"我阿兄在叛军里，被抓去的，不知道死在哪里"）就是吕家老三，找了半个月没找到。
- 辨认的办法：第二十一章补一笔，伊斯叫段老七在每个合葬坑边插一根木签，分不出来的人，从身上取一样小东西（一截衣带、一把木梳、缝着字的衣角）拴在签上。伊斯认的唐字少，签上的字他不认得，只管拴。
- 大历年间吕秀岩在台州做司士参军（颜真卿修《韵海镜源》时他去湖州抄过书，见下），大历末罢官回长安，这才一个人去城南，找到城南老汉的儿子，在第一道沟边的签上认出他娘缝在老二衣角里的一个"吕"字。老汉的儿子告诉他：那天拉人的是大秦寺的胡僧，说的是"分不出来的，埋在一处"。
- 他一直没有去寺里道谢。他说当年不敢认弟弟，如今也没脸先去认收葬弟弟的人；可他也要先看清楚这父子两个是什么样的人，才肯开口。

## 五、情节分段（约 6000 字）

**题记**："念生响应，情发目诚。"（碑文，未用过；说的是心里有念、诚心发出，就有回应，与本章祷告蒙应相合。）

**一、钱差在最后一块上**（建中元年六月底至七月）
- 祠部的批文由裴官人送来，准立（从第四十九章开头挪来）。
- 萨摩安念账：洛阳罗十五的钱到了一半，灵州回信说寺顶又漏、拿不出；衣赐、修殿钱、王店主赊的药都挪完了，还差的，正好是书丹的润笔。
- 萨摩安仍主张晚一年。景净说不等，也不再挪粥。他请全寺从明日起每日午时到殿里，为这块碑祷告，求的不是钱，是"肯写这块碑的人"。
- 萨摩安在账上记"每日午时为碑祷告"，第二天第一个到。
- 冲突：等，还是求；账，还是祷告。

**二、徐公那一头不去**
- 裴官人开出名手：徐浩、颜真卿，润笔都不是寺里出得起的。他又说，大兴善寺已经请了徐公给不空三藏书碑，文章是御史大夫严郢撰的。
- 伊斯想起不空。回忆一段，小说虚构：
  - 永泰元年秋，伊斯从鸣沙回来，满城在传仆固怀恩是被资圣、西明两寺讲《仁王经》讲死的。只有伊斯知道那是赤痢。
  - 那年冬天，不空授特进、试鸿胪卿，加号大广智三藏；伊斯加金紫光禄大夫，告身是判官送到寺里的。
  - 后来一年降诞节，两人在宫门外同候赐物。不空站在前头，紫衣，用粟特话问他："鸣沙那个人，是怎么死的？"伊斯说："下痢。"不空说："我知道。"说完进去了。
- 萨摩安提起上元元年御史奏寺时附的西明寺僧状（第二十八章）。伊斯说不是怕徐公不肯，是人家正给自己的师父写碑，我们去求，是叫人家为难。徐公这一头就不去了。

**三、郭府的一张帖子**
- 伊斯去敦化坊看新立的颜氏家庙碑，想起当年在郭府见过颜公写的郭氏家庙碑。
- 他托侯思远进郭府。郭子仪没有见他，叫判官写了一张帖子、盖了印，侯思远带出来一句话："见不见，是颜公的事。"
- 这句话接着第二十一章郭子仪那句"给不给，给多少，我管不着了"。

**四、颜真卿**（敦化坊）
- 颜公待伊斯很郑重，问了常山、香积寺、灵武的旧事。
- 碑稿读了一个时辰，逐处问"三一""弥施诃""亭午升真"，问碑上把教运和一朝一朝天子接在一起写，是什么意思。景净一一答。
- 颜公说饥者饭之、寒者衣之、死者葬之这几句，他信，他在河北见过这样的人；可是这碑上大半写的东西，他不知道是真是假，署了名就是拿名字作保，他不保自己不知道的事。
- 他荐吕秀岩："吕君笔力足任此碑。至于肯与不肯，须诸公自问。"
- 他怎样认得吕秀岩，写成小说虚构：大历年间他在湖州修《韵海镜源》，从台州来抄书的那个小官，有一回推掉了一笔润笔很高的墓志，因为志主的事是假的。
- 冲突：人情到了，人家的名字却不肯给。伊斯懂：这是另一种不撒谎。

**五、崇贤坊，头一回**
- 吕秀岩看稿看得快，问阿罗诃是什么，问他们信不信。景净说信，吕说"我不信，我写"。
- 接着问景净：字要是写错了意思，算谁的？景净说算他的。吕说碑脚下落着我的名字，写错了，我也要担一半。这一段从第四十九章开头挪来。
- 他没有当场应，说"过几日"，也不提钱。
- 此后几天，他天不亮去西市看了粥棚：景净掌勺，伊斯扛米；又去开远门外看了纳尔赛的木桩。这一段只从叙述里带出，伊斯父子当时不知道。

**六、崇贤坊，第二回**
- 吕秀岩应了。伊斯问润笔，报了萨摩安账上的数。吕说不收。
- 伊斯问为什么，他才说出老二、老三和城南的事，说他怎样没去，怎样后来一个人去，认出衣角上的那个"吕"字。
- 伊斯这才想起第一道沟边那些签，签上的字他当年一个也不认得。
- 伊斯请他七日一荐到寺里坐坐。吕摇头："礼拜便不去了。诸位的心意，我领了。"景净还要再请，他说："碑立在寺里，上头有我的名字，便算我到过了。"
- 不写"敢这么做的唐朝士人不多"这类自夸的话。

**七、午时**
- 回寺正赶上午时。萨摩安在账上润笔那一行底下写"吕先生不受"。
- 祷告完了，萨摩安问：这算不算祷告蒙了应允？那笔账是二十三年前欠下的，祷告是这个月才开始的。
- 伊斯说，那一车一车的人，是他替郭公拉的，拉的时候没想过今天。景净说，主比我们先走了二十几年。
- 末一处停在动作上：伊斯一个人去了一趟城南，第一道沟边的签早就烂了，他在那里站了站，回来添了门口的灯油。或者停在萨摩安记的那一行："午时祷告照旧，所求改为所谢。"

## 六、冲突与解决一览

| 冲突 | 解决 |
|---|---|
| 钱不够：萨摩安要等一年，景净不等也不挪粥 | 每日午时祷告；最后一块由吕秀岩不受润笔补上 |
| 书丹找谁：徐浩是不空一门的书家 | 寺里自己不去，不叫人为难 |
| 颜真卿：人情到了，名字不给 | 颜不保自己不知道的事，荐吕；伊斯认这也是不撒谎 |
| 吕秀岩：要先看清这两个人 | 暗看粥棚、木桩后应允 |
| 吕秀岩自己：当年没敢去收葬 | 说出来；不入教，只留名字 |
| 祷告与旧账：算不算蒙应允 | 留给人物各说一句，叙述不下判断 |

## 七、要连带改的地方（待作者定后再动）

1. **第二十一章**：插一两句，写木签和拴在签上的遗物。不点破，不提吕姓。
2. **第四十七章**："裴官人荐的那位写字的吕先生，润笔是托裴官人先问过的"改为"书丹请名手，润笔照裴官人打听来的行情"，不提吕秀岩。
3. **第四十九章《立碑》**：开头请吕秀岩那一大段删去，"写错了我也要担一半"移到本章，只留"十月石头运进寺"以后的内容。祠部准立一句也移到本章。吕秀岩立碑那夜来看字一段照旧，与"礼拜便不去"不冲突：他来是看字，不是来礼拜。
4. **第五十章《郭子仪》**：可加一句郭问"颜清臣没有写？"，伊斯答"吕先生写的"，非必需。
5. **续写备忘**：添本章已定细节，以及吕家、不空、颜真卿三条设定。

## 八、需要作者定的

1. 吕家旧事和第二十一章常乐坊后生的对接，可不可以；要不要在第二十一章补木签。
2. 不空与伊斯的交集：上面写的是三处（永泰元年《仁王经》法会与仆固怀恩之死、同年两人加官、降诞节宫门外一句粟特话）。要不要两人当面说话，还是只让伊斯远远看见？
3. 颜真卿认得吕秀岩的由来（湖州修《韵海镜源》时推掉一篇假墓志），可不可以。
4. 结尾停在哪一处：伊斯去城南看签，还是萨摩安那一行账。

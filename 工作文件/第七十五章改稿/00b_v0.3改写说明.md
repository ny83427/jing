# v0.4 补改：对质一节加心理战（2026-11-25）

作者要求对质更尖锐，加心理战；采用"只说真话的假象"方案，不另埋假碑（假碑是以行撒谎，与本章"不说谎"及全书伦理相抵）。章内其余部分同 v0.3。

## 对质的走法

1. 县尉先依牒判"县里的文书够不着"，卢守冲冷笑"这话我替你记着"，亮出靠山：赵炼师在三殿上说过长安有块胡碑辱圣祖，"圣人没有说话，就是记下了"（半真半假，卢守冲自己也是听观主转说的）。县尉动摇，要挖开看一看。
2. 景福"这个我不说"；卢守冲"你不说，我自己找"，在空地上推断：几千斤抬不远、只能就近埋，碑面朝寺门，字要朝上只能往后倒——走到碑后头，用脚尖点地，"就在我脚底下"。点的正是埋碑处。众人色变，观里两人举起镐。
3. 灵宝在枣树下开口："道长看得准，那就在那里挖吧。慢慢挖……四娘，天热，给道长和少府倒两碗水来。"又说"咱们奉公守法……王命是王命"，请县尉在簿子上记清哪一块地、几时下镐、谁叫挖的，因为院子已是使司产业，明天巡院点收要对账，牒是杨判官押的，缓三日也是杨判官给的。
4. 县尉知功德使司是内官的衙门，不愿夹在赵炼师与内官之间，改口"挖不挖，道长自己定。要挖，簿子上记道长的名字"。卢守冲心生疑虑：准成这样人家还不慌，怕底下是空的；挖出空坑，名字在县簿上，明天私掘使司产业，赵炼师未必替他说话；杨判官与胡寺的瓜葛他打听不出。出汗，终于"放下吧"。
5. 卢守冲临走："你们这一寺的人，嘴上不说谎，心眼倒是多。"灵宝："我们心眼不多，就是不撒谎。道长要是不信，现在挖也来得及。"
6. 县尉此时才记"埋了，量为处置"，出门对枣树下拱手。
7. 散场后景福腿软、背上湿透；问灵宝怕不怕真挖，灵宝"怕。我的手到现在还在抖，你摸摸"——"我说的那些话，没有一句是假的……他要是真挖下去，那就是主许了的，咱们明天照样站晨课。他不挖，是他自己心里的事，不是我吓的。"
8. 章末仍停在景福傍晚看空地、关寺门。

# v0.5 外审修订（2026-11-25，作者审定提交）

依据：作者转来的 GPT 审稿意见（对提交 9d165ec，第七十五章 v0.4）。六条全部采纳，只在卢守冲退让的理由上取了与意见一致、而保留心理战的写法。

1. **开头接缝。** 第七十四章末景福已叠牒入怀、再按碑；本章删去再叠再揣，从"景福把手从碑上拿下来"起笔。
2. **念牒的人。** 第七十四章念牒的是景福，灵宝在听；景福问话改为"方才我念完了牒，你低声说了一句什么"。
3. **"使司产业"口径。** 第七十四章景福说缓限之内"寺还是寺"，第七十六章点收后才没官；灵宝原说"这院子从前天起，就是使司的产业了"，改为"明天巡院就来点收……院里多了一个坑，是谁叫挖的，请少府今天就记清楚"。
4. **放碑。** 景福刚下令"碑倒的那一边，谁也不许站"，自己又跳下坑托碑头，自相矛盾。改为景福跪在坑沿上喊号，碑头落沙未磕十字；碑脚落下时沙溅上坑沿；碑躺定后景福才下坑看一圈，一个字也没有磕坏。
5. **补碎石。** 删"我想师父要是在，也会叫我补"，让景福自己担这个与师父不同的决定。
6. **对质收紧。**
   - 卢守冲点中埋碑处后，删去众人一串反应，只留"景福的脸一下子白了。卢守冲看见了，嘴角往上挑了一挑"。
   - 卢守冲的心理改为：他看清了景福的脸色，十有八九碑就在脚下；他怕的是挖出来以后——使司牒上叫主持处置的东西，他起出来，县簿记着他的名字，杨判官问起来，赵炼师肯不肯为一块胡碑得罪内官的衙门；赵炼师那几句话他也是听观主转说的。原段约一半。
   - 心理战仍在：灵宝的从容与"请少府记清楚是谁叫挖的"，把卢守冲手里的把握变成了他自己要担的风险。
7. **结尾。** 删灵宝"他不挖，是他自己心里的事，不是我吓的"，停在"他要是真挖下去，那就是主许了的，咱们明天照样站晨课"，他这一招里有多少信靠、多少盘算，不说破。

8. **作者复核后恢复两处（2026-11-25）。**
   - 群像反应恢复，改由卢守冲的眼睛看出去（"卢守冲没有看地，他在看人……一个一个看过去，嘴角往上挑了一挑"）：v0.5 里他退让的理由已改为怕担后果，群像不再与之矛盾，反而是他"十有八九"的依据，也给灵宝的从容垫底。他的内心相应改为"这一院子人的脸色，他一个一个都看见了"。
   - 杨判官两句恢复（"四五十年没有替谁说过一句话，偏偏给这座胡寺缓了三天。这里头有什么瓜葛，他打听不出来"）：与第七十三章阿奴的粥碗构成卢守冲不知、读者知道的反讽，是隐藏的眷顾所在。"到底说没说过，说的是不是这一块碑"仍删（与"听观主转说的"重复）。

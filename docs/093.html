附录五　景教碑之五：宾礼与贞观朝的外来宗教

碑上说，贞观九年阿罗本到长安，太宗派宰相房玄龄带着仪仗到西郊迎接，请进宫里翻译经书、询问教义，三年后下诏准他建寺度僧。这样的接待，在唐初是寻常，还是破格？这一篇先细读碑文，再对照其他史料，把它放进唐代宾礼的常规和太宗朝接待外来宗教人士的实例中比较，最后汇总贞观年间对外来宗教的政策。

一、结论先行

  1. 规格偏高，但并非空前。按碑文所说，太宗派首席宰相房玄龄率仪仗到西郊迎接，又在宫中译经问道。这高于唐代宾礼对一般外国使者的常规接待（通常由鸿胪寺官员在客馆迎劳），接近对高僧、贵宾的礼遇。但同一时期，房玄龄也主持过印度僧波颇的译场，又以留守身份迎接过玄奘回国，宰相出面接待外来宗教人士在太宗朝并不罕见。
  2. 最“特殊”的不是迎接，而是诏书。贞观十二年（638）的诏书准其建寺、度僧二十一人，并明言“宜行天下”，这在《唐会要》中有独立记载，是可靠的史实。相比之下，郊迎的细节只见于一百四十六年后景教自己立的碑，属于孤证。
  3. 碑文的描写有修辞成分。景净在 781 年追述往事，有意把阿罗本塑造成被太宗隆重礼遇的“上德”，以此为景教在德宗朝争取地位。描写本身可能有事实基础，但细节（“总仗”“入内”“禁闱”）不宜照单全收。
  4. 接待的性质是“宾礼”。“宾迎入内”的“宾”字点明了身份：阿罗本是以外国来宾的身份被接待的，而不是以宗教领袖的身份。这符合唐初把外来宗教纳入“宾客”管理（隶属鸿胪寺）的制度逻辑。

下面逐项论证。

《尊经》跋语的记载很值得注意：它说阿罗本到中国后“奏上本音”，即用自己的语言上奏，由房玄龄、魏徵“宣译奏言”。这说明房玄龄确实参与了阿罗本的事，但他的角色更像是负责转达奏议的宰相，而非一定亲自出城迎接。比利时学者钟鸣旦主编的《中国基督教手册》推测，阿罗本说的“本音”是粟特语而不是波斯语，因为粟特语是当时中亚的通用语。

三、唐代宾礼的常规程序

要判断阿罗本的待遇是否特殊，先要知道常规是什么。

1. 礼典规定

唐代修过三部礼典：《贞观礼》（637 年颁行，房玄龄等主修）、《显慶礼》（658）、《开元礼》（732）。三部都有“宾礼”。朱溢《唐至北宋时期宾礼的礼仪空间》（2014）引《贞观礼》的概括说，宾礼用于接待四夷君长及其使者，程序包括“遣使迎劳、授馆、将币、摈享之节”。

《开元礼》所列的程序是：

  1. 迎劳授馆：朝廷派使者慰劳来宾，并安排住处；
  2. 戒见日：通知来宾觐见的日期；
  3. 朝见：入宫觐见皇帝；
  4. 宴会：皇帝赐宴；
  5. 朝辞：辞别。

2. 迎劳在哪里，由谁执行

据朱溢的研究，《开元礼》中“迎劳授馆”与“戒见日”这两步在鸿胪客馆进行。鸿胪客馆属鸿胪寺，在皇城之内。礼典只说朝廷“遣使”，并没有规定使者的官品，更没有提到宰相出城迎接。

觐见的规格也有区别：外国君主（蕃主）在太极殿觐见，可以升殿就座；外国使者（蕃使）在皇帝所在的殿觐见，立于庭中。朱溢还指出，各国之间待遇的差异主要在于“蕃主”与“蕃使”的区别，而非国家大小。

3. 负责机构

  • 鸿胪寺：掌宾客及凶仪之事。下设典客署，负责外国来宾的接待、供给。
  • 鸿胪客馆：外国使者的住所。

四、太宗朝的实际案例比较

但礼典规定和实际操作常有出入。比较同时代的几个实例，更能看出阿罗本待遇的分量。

案例一：印度僧波颇（武德九年十二月到长安）

据道宣《续高僧传》卷三《波颇传》：

  • 波颇是中天竺刹帝利出身的高僧，曾在那烂陀寺跟随戒贤学习，后北上到西突厥叶护可汗牙帐传法，受到可汗礼遇。
  • 武德九年（626），唐朝宗室高平王出使西突厥时与他相见。叶护可汗不肯放人，高平王奏闻朝廷，朝廷下敕征召，波颇随高平王入唐，当年十二月到京城。
  • 太宗敕令他住在大兴善寺。后“蒙引内见”，即被引入宫中接见；赐彩四十段及宫中新制的僧衣，随行的五位僧人也增加供给，并多次慰问，碑传形容为“劳接殊伦”（接待与慰劳超出常例）。
  • 贞观三年（629）三月，太宗下诏在大兴善寺创立译场，召集十九位大德参与。又敕上柱国、尚书左仆射房玄龄和太子詹事杜正伦“参助勘定”，太府卿萧璟“总知监护”，百司供送，物资丰足。
  • 贞观六年（632）译成三部三十五卷，太宗敕令各写十部流通天下，并命太子庶子李百药作序。

比较：波颇由朝廷主动征召，太宗在宫中接见，又派房玄龄等高官参与译经。这与阿罗本的“翻经书殿，问道禁闱”在模式上非常接近。差别在于，史传没有说房玄龄出城迎接波颇。

案例二：玄奘回国（645 年）

据慧立、彦悰《大慈恩寺三藏法师传》卷五、卷六：

  • 贞观十九年（645）玄奘回到长安时，太宗正在洛阳准备东征高丽。玄奘到沙州时先上表报告，太宗敕令西京留守、左仆射房玄龄派有关衙门迎接。
  • 但玄奘急于在太宗出征前赶到，日夜兼程，突然到达长安西郊的漕上，“官司不知迎接，威仪莫暇陈设”，倒是闻讯赶来观看的百姓挤满街道，他只得在漕上过夜。
  • 正月景子（即丙子日，唐人避讳改“丙”为“景”），房玄龄派右武侯大将军侯莫陈寔、雍州司马李叔眘、长安县令李乾祐等人奉迎，从漕上入城，安置在都亭驿。
  • 次日，长安诸寺在朱雀街南举行盛大的迎经像仪式。
  • 此后玄奘赶到洛阳，在仪鸾殿谒见太宗。

比较：玄奘是唐朝最负盛名的高僧，太宗事先下敕由房玄龄安排迎接。即便如此，房玄龄是派属官去迎，而非亲自出城；迎接地点也在长安西郊（漕上），由此入城。若碑文所说属实，房玄龄亲自“总仗西郊”迎接阿罗本，规格比后来迎接玄奘还要高一等。

按：这个比较需要谨慎。玄奘回国时房玄龄的身份是留守，太宗本人不在长安，而且玄奘是突然到达，临时组织。阿罗本到达时太宗就在长安，可以从容安排。两者条件不同，不能简单说阿罗本的待遇高过玄奘。

案例三：祆教穆护何禄（631 年）

据北宋赞宁《大宋僧史略》卷下：

贞观五年，有传法穆护何禄，将祆教诣阙闻奏，勅令长安崇化坊立祆寺。

宋代志磐《佛祖统纪》卷三十九所记大致相同。

比较：何禄是祆教传法者（“穆护”即祆教祭司），亲自到宫门上奏，朝廷敕令在长安立祆寺。史料没有提到任何迎接仪式。何禄姓“何”，是粟特何国（今乌兹别克斯坦撒马尔罕附近）的人。

按：《僧史略》同一条下说这座祆寺“号大秦寺，又名波斯寺”，显然把祆教和景教混为一谈。陈垣《火祆教入中国考》（1923）早已指出宋人对三夷教多有混淆，这条材料的细节要谨慎使用。但它至少说明，在阿罗本之前四年，已有外来宗教的传法者以上奏的方式在长安取得立寺许可。

案例四：天竺方士那罗迩娑婆寐（648 年）

据《旧唐书·西戎传·天竺》与《资治通鉴》卷一九九、二〇〇：

  • 贞观二十二年（648），王玄策出使天竺，俘虏阿罗那顺，带回一名自称两百岁、能炼长生药的方士那罗迩娑婆寐。
  • 太宗深加礼敬，让他住在金飚门内，造延年之药，派兵部尚书崔敦礼监督，又让使者到各地采集药物。
  • 药成，太宗服后无效。太宗死后，高宗将此人放还。

比较：这一例与宗教传教无关，但说明太宗对来自西方的“奇人异术”有很大兴趣，并愿意给予优厚待遇、派高官监管。

五、对碑文描写的史料批判

1. 碑文写于一百四十六年之后

景净在 781 年撰文时，距阿罗本入华已有一百四十六年。他依据的可能是教会内部的传承、寺中保存的诏书副本，以及《唐会要》一类官方文献所据的原始档案。贞观十二年诏书的文字与《唐会要》高度吻合，说明景净手中有可靠的诏书文本。但“总仗西郊”一类的场面描写，没有档案可以依据。

2. 改写的痕迹

富安敦在 1996 年的专文《准许基督教在华传播的 638 年诏书》（The Edict of 638 Allowing the Diffusion of Christianity in China）中认为，《唐会要》保存了诏书的大部分原文。Deeg 进一步比较了两个版本：《唐会要》本把阿罗本称为“波斯僧”，碑文改为“大秦国大德”；《唐会要》本作“远将经教来献上京”，碑文改为“远将经像”；寺名也从“波斯寺”回改为“大秦寺”。

这些改写都有一个共同方向：淡化与波斯的联系，突出“大秦”（罗马、西方圣地）的来源。Deeg 认为，这反映了景教团体在萨珊王朝灭亡、安史之乱后唐人猜忌胡人的背景下，自我身份从“波斯”转向“大秦”。

既然诏书的措辞都经过改写，场面描写就更可能经过渲染。

3. 文学套语

碑文写阿罗本“占青云而载真经，望风律以驰艰险”，用的是东方朔《海内十洲记》中西域使者候风而至、来献异物的典故。Deeg 指出这是一种用典，并把阿罗本称为一个“传说式”的人物。这类套语说明，景净在描写阿罗本入华时，是按照中国史书中“远人慕化来朝”的范式来写的。

4. 与佛教僧传的相似

阿罗本的故事（远道携经而来—朝廷隆重迎接—宫中译经—皇帝下诏弘法）与汉明帝时摄摩腾、竺法兰携经东来、在洛阳白马寺译经的传说，以及波颇、玄奘的经历，在结构上非常相似。

按：景净熟悉佛教文献（他后来还与般若合译佛经），很可能有意借用了高僧东来的叙事模式。这不等于事情是虚构的，而是说碑文的写法遵循了当时宗教史叙事的惯例。

5. 立碑的现实目的

立碑的 781 年，德宗刚即位不久，朝中有整顿僧道的议论。景教团体立碑追述太宗以来历代皇帝的恩宠，有明确的现实意图：提醒新皇帝，景教从开国之初就得到最高礼遇，是一个与唐朝国运相始终的宗教。阿罗本受宰相郊迎的描写，正是这一叙事的起点。

六、怎样理解“宰相郊迎”

如果承认碑文的描写有一定的事实基础，那么房玄龄出面接待阿罗本，可以从几个方面理解：

1. 房玄龄的职责

房玄龄在贞观年间以尚书左仆射总领百官，“总百司，掌纲纪”，许多涉及外来宗教的事务都由他经手：波颇译场他参助勘定，玄奘回国他安排迎接，阿罗本上奏他宣译奏言。他还主修《贞观礼》，熟悉宾礼。由他出面接待阿罗本，与其说是格外抬举阿罗本，不如说是这一类事务的常规负责人。

2. 太宗的兴趣

太宗对来自西方的事物有浓厚兴趣：对波颇、玄奘的佛学，对那罗迩娑婆寐的长生术，对西域的地理风俗，都极为关心。他后来令玄奘撰写《大唐西域记》，就是想了解西域情况。阿罗本带来的是一种从未见过的宗教，太宗想亲自了解，合乎他的性格。

3. 政治考虑

贞观九年（635）唐朝刚刚打败吐谷浑，正在经营西域。贞观四年（630）太宗已被西北各族尊为“天可汗”。接待一位从遥远西方来的宗教领袖，展示“远人来朝”，符合唐朝的天下秩序观念。

4. 宗教政策的需要

太宗即位初年整顿佛教，严禁私度，同时又给予正规僧团支持。对新来的宗教，朝廷的态度是先审查、再许可、纳入管理。“翻经书殿，问道禁闱，深知正真，特令传授”，正是一个审查过程：先把经典译成汉文，弄清楚教义，确认无害，然后准许传授。从这个角度看，“问道”与其说是尊崇，不如说是审查。

七、唐太宗朝的外来宗教政策汇总

1. 总体原则

（1）华夷一体的天下观

太宗晚年自述成功之道，说：“自古皆贵中华，贱夷狄，朕独爱之如一，故其种落皆依朕如父母。”（《资治通鉴》卷一九八，贞观二十一年）这种态度为外来宗教在长安立足提供了政治空间。

（2）“随方设教”的宗教观

贞观十二年诏书开头说：“道无常名，圣无常体，随方设教，密济群生。”意思是：真理没有固定的名称，圣人没有固定的形体，各地各有其教化方式，都在暗中救济众生。这是唐朝官方对外来宗教的理论立场：不以本土宗教为唯一真理，承认各种教化各有其用。这句话后来被反复引用，被视为唐朝宗教宽容政策的纲领。

（3）以“宾客”身份管理

唐初把佛教、道教都放在鸿胪寺下的崇玄署管理（武则天延载元年即 694 年以后，僧尼改隶礼部祠部）。鸿胪寺本是掌管外国宾客的机构，把宗教放在这里，反映出佛教作为“外来之教”的身份。直到会昌五年（845）武宗灭佛时，诏书还说要把僧尼划归主客司管理，“显明外国之教”，同时勒令大秦（景教）、穆护（祆教）三千余人还俗。可见“外国之教”的定位贯穿唐代始终。

（4）国家控制

宽容不等于放任。唐朝对一切宗教都实行严格的国家控制：

  • 寺院的设立须经朝廷敕准，寺额由朝廷颁给；
  • 度僧（剃度出家）的人数由朝廷规定，如阿罗本获准度僧二十一人；
  • 私自出家（私度）严加禁止。

2. 分教政策

3. 胡人的法律地位

《唐律疏议·名例律》规定：“诸化外人，同类自相犯者，各依本俗法；异类相犯者，以法律论。”即外国人之间同族相犯的，按其本国习俗处理；不同族之间相犯的，按唐律处理。这一原则保障了胡人在宗教、婚姻等方面保持本俗的权利，是外来宗教得以在胡人社群中延续的法律基础。

4. 接待外来宗教人士的模式

综合以上案例，太宗朝接待外来宗教人士大致形成以下模式：

  1. 事先知会：来者先通过边州、使节或上表让朝廷知道（波颇由使者奏闻，玄奘先上表，阿罗本是“帝使”迎接，说明事先已知）；
  2. 朝廷派员迎接：视来者的分量派不同级别的官员，最高可至宰相；
  3. 安置于寺院或宾馆：如波颇住大兴善寺，玄奘住都亭驿后入弘福寺；
  4. 皇帝接见问话：了解其学说与来历；
  5. 翻译经典：由朝廷组织或提供条件，往往派高官监护；
  6. 审查后下诏：确认其教无害，准许传授，或建寺、度僧；
  7. 纳入国家管理：寺额、僧数、所属机构都由朝廷决定。

阿罗本走完了这个模式的全部七步，而且每一步都达到了较高规格。这是他的特殊之处：不是哪一项待遇空前绝后，而是他作为一种全新宗教的代表，在三年之内就完整地获得了与佛教高僧相当的待遇和合法地位。

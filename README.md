# 景

景教在唐朝的沉浮。长篇历史小说，作者老杨。

## 目录结构

- `正文/`：小说正文，一章一个文件。文件名格式为「三位序号-卷-章-回目.md」，序章为 000，尾声为 067，后记为 099。
- `工作文件/`：大纲、续写备忘（已定的人物与设定）、统稿记录（待作者决定的问题）。
- `封面/`：总封面、三卷封面、三卷封底、三卷本合集效果图。网页用 JPG；`封面/原图/` 是 2 倍分辨率 PNG 原图（封面 1680×2380，合集 3200×2000）。
- `工具/build_site.py`：从 `正文/` 生成阅读网站，输出到 `docs/`。`工具/site/` 放网页的样式和脚本。
- `图片/`：正文插图。Markdown 里用 `../图片/文件名` 引用，生成网站时复制到 `docs/img/fig/`，图片说明取自图片的替代文字。
- `预告片/`：预告片成片。生成画面和配乐的脚本在 `工具/预告片/`，用法见脚本开头。
- `docs/`：GitHub Pages 网站（自动生成，不要手改）。
- `修改记录.md`：每一版改了什么，按时间倒序排列。

## 版本约定

- 每章文末一行标注版本号、最后修改时间（美国中部时间）和状态。
- v0.x 为草稿，每改一轮加 0.1；v1.0 为定稿。
- 每次提交都在提交说明和 `修改记录.md` 里写明改了哪些章、改了什么、为什么改。

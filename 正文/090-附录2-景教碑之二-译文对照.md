# 附录二　景教碑之二：译文对照

附录一讲了碑的大略，这一篇把碑文全文录出：左栏是碑文原文，右栏是白话译文，必要处附简短注释。碑下和碑侧的叙利亚文，只录拉丁字母转写（节略）和汉译，转写依通行的学术本，不是逐字摹刻。碑中关于伊斯一段的详细讨论见附录三，其余人物见附录四。

## 校勘说明

碑文录自《大正新修大藏经》第五十四册第二一四四号（CBETA 电子版），原碑没有标点，标点与分段为本书所加。底本个别明显的错误，参照碑石拓本与 Eccles、Lieu 二〇一六年的 SERICA 译注本订正如下：

- "阿罗诃欤判。十字"，断句改为"阿罗诃欤！判十字"；
- "总玄摳"，碑字作"摳"，读为"樞"；
- "宗周德喪"的"喪"，底本作异体字，今改通行字；
- "腾淩激曰"作"腾淩激日"；
- "大耀森文曰"作"大耀森文日"；
- 颂末"道惟广兮应惟密强。名言兮演三一"，断句改为"道惟广兮应惟密，强名言兮演三一"；
- 碑侧僧名"延和"，底本作缺字，据叙利亚文对照补。

文字保留繁体，碑中缺损的字以"□"表示。

## 一、序：真主、创世与堕落

| 碑文原文 | 白话译文 |
| --- | --- |
| 粵若：常然真寂，先先而無元；窅然靈虛，後後而妙有。總玄摳而造化，妙衆聖以元尊者，其唯我三一妙身無元真主阿羅訶歟！ | 啊！那恒常不变、真实寂静者，在一切起始之先而自身无始；那幽深灵妙、虚而无形者，在一切终末之后而奥妙长存。他总揽玄妙的枢机而创造化育，使众圣得其妙用、尊他为至高元首——这位，岂不就是我们三一妙身、无始的真主阿罗诃吗！<br>〔注〕阿罗诃：叙利亚语 Alāhā（上帝）之音译。“摳”碑作此形，诸本多读为“樞”。 |
| 判十字以定四方，鼓元風而生二氣。暗空易而天地開，日月運而晝夜作。匠成萬物，然立初人，別賜良和，令鎮化海。 | 他划出十字，定立四方；鼓动元始之风，生出（阴阳）二气。幽暗虚空为之一变，天地由此开辟；日月运行，昼夜于是形成。他巧手造成万物，然后立起最初的人，又特别赐给人良善和顺的本性，叫他管理所造的世界。<br>〔注〕元风：多解作圣灵（参《创世记》1:2“神的灵运行在水面上”）。 |
| 渾元之性，虛而不盈；素蕩之心，本無希嗜。 | 人起初浑朴纯一的本性，虚怀而不自满；素朴坦荡的心，本来没有贪求嗜欲。 |
| 洎乎娑殫施妄，鈿飾純精，間平大於此是之中，隙冥同於彼非之內。 | 等到娑殚（撒但）施展虚妄，用浮华的装饰涂抹那纯粹精一之物：在人以为“是”的地方离间了平和与宏大，在人以为“非”的地方暗中混同了是非。<br>〔注〕娑殚：叙利亚语 Sāṭānā 音译。此句文义艰深，诸家断句、训释分歧甚多，大意是撒但以诡诈颠倒是非，使人失去起初的和谐。 |
| 是以三百六十五種，肩隨結轍，競織法羅。或指物以託宗，或空有以淪二，或禱祀以邀福，或伐善以矯人。智慮營營，恩情役役，茫然無得，煎迫轉燒。積昧亡途，久迷休復。 | 于是三百六十五种教派纷纷兴起，比肩相随，车辙相接，争相编织各自教法的罗网：有的指认某物为信奉的宗主，有的执著于“空”“有”而陷入二元，有的以祈祷祭祀求取福报，有的夸耀己善来压服别人。人的心思营营不休，情欲役使身心，茫然一无所得，焦灼煎迫，愈烧愈烈。愚昧日积，迷失道路，长久迷惑，不能回头。<br>〔注〕“指物以托宗”多指偶像或自然崇拜，“空有以沦二”多指佛教空有之辨与摩尼教二宗论，“祷祀邀福”指祭祀求福之教，“伐善矫人”或指以行善自矜者。 |

## 二、序：弥施诃降生与救赎

| 碑文原文 | 白话译文 |
| --- | --- |
| 於是我三一分身景尊彌施訶，戢隱真威，同人出代。神天宣慶，室女誕聖於大秦；景宿告祥，波斯睹耀以來貢。 | 于是我们三一之中分身降世的景尊弥施诃，收敛隐藏他真实的威严，取了人的样式来到世间。天使宣告喜讯，童女在大秦生下圣者；明亮的星宿报告祥瑞，波斯人望见光耀便前来进贡。<br>〔注〕弥施诃：叙利亚语 Mšīḥā（弥赛亚、基督）。“波斯睹耀以来贡”指东方博士（《马太福音》2章）。 |
| 圓二十四聖有說之舊法，理家國於大猷；設三一淨風無言之新教，陶良用於正信。 | 他成全了二十四位圣人有言说的旧法，用大道治理家国；又设立三一净风无言的新教，在正信中陶冶人的良善之用。<br>〔注〕二十四圣：多解作旧约先知（或旧约二十四卷）。净风：圣灵。 |
| 制八境之度，鍊塵成真；啟三常之門，開生滅死。 | 他定立八种境界的法度，把尘俗之人锻炼成真；开启“三常”之门，开出生命，灭除死亡。<br>〔注〕八境：或指“八福”（《马太福音》5章），或指八种德行。三常：或解作信、望、爱，林悟殊认为借自摩尼教术语。 |
| 懸景日以破暗府，魔妄於是乎悉摧；棹慈航以登明宮，含靈於是乎既濟。能事斯畢，亭午昇真。 | 他高悬光明的太阳，攻破幽暗的地府，魔鬼的虚妄由此尽被摧毁；他划动慈悲之舟，登上光明之宫，一切有灵之物由此得蒙救度。大功既已完成，他在正午升天归真。<br>〔注〕此段只言救赎与升天，未明言十字架受难，是碑文历来受人议论之处。 |

## 三、序：经典、礼仪与戒规

| 碑文原文 | 白话译文 |
| --- | --- |
| 經留二十七部，張元化以發靈關；法浴水風，滌浮華而潔虛白。 | 他留下经典二十七部，张扬根本的教化，开启灵性的关门；以水与风（圣灵）施行法浴，洗去浮华，使心地洁白虚明。<br>〔注〕二十七部：新约二十七卷。法浴：洗礼。 |
| 印持十字，融四照以合無拘；擊木震仁惠之音，東禮趣生榮之路。 | 以十字为印记持守，融合四方的光照，使人合一而无拘碍；敲击木板，震响仁爱恩惠之音；面向东方礼拜，奔向生命荣耀之路。<br>〔注〕击木：东方教会以敲击木板（nāqōšā）召集礼拜。东礼：向东礼拜。 |
| 存鬚所以有外行，削頂所以無內情。不畜臧獲，均貴賤於人；不聚貨財，示罄遺於我。 | 留须，是为表明有外在的德行；剃顶，是为表明内心没有私情。不蓄养奴婢，对人一视同仁、无分贵贱；不积聚财货，表明自己倾尽所有、一无所留。<br>〔注〕削顶：东方教会教士剃冠顶（tonsure）。 |
| 齋以伏識而成，戒以靜慎為固。七時禮讚，大庇存亡；七日一薦，洗心反素。 | 斋戒以降伏私心而成全，戒律以宁静谨慎为根基。每日七次礼拜赞美，广为生者与亡者祈求庇护；每七日举行一次献祭，洗涤心灵，返回本真。<br>〔注〕七时：每日七次祈祷。七日一荐：主日圣餐（感恩祭）。 |
| 真常之道，妙而難名；功用昭彰，強稱景教。 | 这真实恒常之道，奥妙而难以命名；只因它的功用昭然彰显，勉强称它为“景教”。<br>〔注〕景：光明、广大之义。语式仿《老子》“吾不知其名，字之曰道，强为之名曰大”。 |
| 惟道非聖不弘，聖非道不大；道聖符契，天下文明。 | 道若没有圣王便不能弘扬，圣王若没有道便不能伟大；道与圣王相合如符契，天下才得文明。<br>〔注〕此句为全文枢纽：以下转入“圣”（唐朝诸帝）与“道”（景教）相得的历史叙述。 |

## 四、序：太宗朝——阿罗本入华与贞观十二年诏

| 碑文原文 | 白话译文 |
| --- | --- |
| 太宗文皇帝，光華啟運，明聖臨人。大秦國有上德曰阿羅本，占青雲而載真經，望風律以馳艱險。貞觀九祀，至於長安。 | 太宗文皇帝以光辉开创国运，以圣明君临万民。大秦国有一位上德之人，名叫阿罗本，他占观青云的征兆，载着真经；观测风向音律，奔越艰难险阻。贞观九年（635），到达长安。<br>〔注〕“占青云”“望风律”用汉代以来西域使者“候风而至”的典故（参东方朔《海内十洲记》）。 |
| 帝使宰臣房公玄齡總仗西郊，賓迎入內。翻經書殿，問道禁闈。深知正真，特令傳授。 | 皇帝派宰相房玄龄公率领仪仗到西郊，以宾礼迎入宫中。在书殿翻译经典，在禁中询问其道，深知其正直真实，特命准予传授。<br>〔注〕关于此次接待的规格，详见附录五。 |
| 貞觀十有二年秋七月，詔曰：「道無常名，聖無常體。隨方設教，密濟群生。大秦國大德阿羅本，遠將經像，來獻上京。詳其教旨，玄妙無為；觀其元宗，生成立要。詞無繁說，理有忘筌。濟物利人，宜行天下。」所司即於京義寧坊造大秦寺一所，度僧二十一人。 | 贞观十二年（638）秋七月，下诏说：“道没有固定的名称，圣人没有固定的形体；随各方水土设立教化，暗中救济众生。大秦国大德阿罗本，远道带着经书和圣像，来献于京城。详察他的教旨，玄妙而无为；观察他的根本，在于生成万物、确立要道。言辞没有繁琐之说，道理达到得鱼忘筌之境。济助万物，利益人民，应当通行天下。”有关衙门随即在京城义宁坊建造大秦寺一所，剃度僧人二十一名。<br>〔注〕《唐会要》卷四十九所载同一诏书作“波斯僧阿罗本，远将经教来献上京”，“于义宁坊建寺一所”，无“大秦”字样；天宝四载（745）始改波斯寺为大秦寺。碑文是按781年的称呼回改的。 |
| 宗周德喪，青駕西昇；巨唐道光，景風東扇。旋令有司，將帝寫真轉摸寺壁。天姿汎彩，英朗景門；聖迹騰祥，永輝法界。 | 周朝德衰之时，（老子）驾青牛西去；大唐道运光明，景教之风向东吹来。不久又命有关衙门把皇帝的画像摹绘到寺壁上。天子容颜光彩焕发，照亮景教之门；圣迹腾起祥瑞，永远辉耀法界。<br>〔注〕“喪”字底本作异体，今改通行字。“青驾西升”用老子出关西去的传说，与“景风东扇”对举。 |

## 五、序：大秦国风物

| 碑文原文 | 白话译文 |
| --- | --- |
| 案《西域圖記》及漢魏史策，大秦國南統珊瑚之海，北極衆寶之山，西望仙境花林，東接長風弱水。其土出火浣布、返魂香、明月珠、夜光璧。俗無寇盜，人有樂康。法非景不行，主非德不立。土宇廣闊，文物昌明。 | 据《西域图记》以及汉、魏史书记载：大秦国南边统辖珊瑚之海，北边直抵众宝之山，西边可望仙境花林，东边连接长风弱水。那里出产火浣布、返魂香、明月珠、夜光璧。民风没有盗贼，人民安乐康宁。法度非景教不行，君主非有德不立。疆土广阔，文物昌明。<br>〔注〕《西域图记》为隋裴矩所撰。这一段几乎全取《后汉书·西域传》《魏略·西戎传》中的大秦传说，并非实地见闻。 |

## 六、序：高宗至玄宗朝

| 碑文原文 | 白话译文 |
| --- | --- |
| 高宗大帝，克恭纘祖，潤色真宗，而於諸州各置景寺，仍崇阿羅本為鎮國大法主。法流十道，國富元休；寺滿百城，家殷景福。 | 高宗大帝恭敬地继承祖业，为真教增添光彩，在各州分别设立景寺，并尊阿罗本为“镇国大法主”。教法流布全国十道，国家富足、大为安宁；寺院遍满百城，家家富有光明之福。<br>〔注〕“十道”“百城”多被认为是修辞性夸张，实际景寺数量有限（林悟殊有专文考释碑中景寺数量词）。 |
| 聖曆年，釋子用壯，騰口於東周；先天末，下士大笑，訕謗於西鎬。 | 圣历年间（698—700），佛教徒倚仗势力，在东周（洛阳）大肆攻讦；先天末年（712—713），浅陋之士放声大笑，在西镐（长安）诽谤（景教）。<br>〔注〕“下士大笑”用《老子》“下士闻道，大笑之”，一般认为指道教一方。 |
| 有若僧首羅含、大德及烈，並金方貴緒，物外高僧，共振玄網，俱維絕紐。 | 有僧首罗含、大德及烈等人，都是西方名门之后、超然物外的高僧，一同重振玄妙的纲维，共同接续那将断的纽带。<br>〔注〕金方：西方（五行西方属金）。 |
| 玄宗至道皇帝，令寧國等五王親臨福宇，建立壇場。法棟暫橈而更崇，道石時傾而復正。 | 玄宗至道皇帝命宁王等五位亲王亲临寺院，建立坛场。教法的栋梁一度弯折而更加高耸，道的基石一时倾斜而又复归端正。 |
| 天寶初，令大將軍高力士送五聖寫真寺內安置，賜絹百匹，奉慶睿圖。龍髯雖遠，弓劍可攀；日角舒光，天顏咫尺。 | 天宝初年，命大将军高力士护送五位先帝的画像到寺内安放，赐绢一百匹，奉迎庆贺圣容。先帝虽已乘龙远去，遗下的弓剑仍可攀援追念；画中帝王额角舒展光辉，龙颜宛若近在咫尺。<br>〔注〕五圣：高祖、太宗、高宗、中宗、睿宗。“龙髯”“弓剑”用黄帝乘龙升天、群臣攀龙髯、遗下弓剑的典故（《史记·封禅书》）。 |
| 三載，大秦國有僧佶和，瞻星向化，望日朝尊。詔僧羅含、僧普論等一七人，與大德佶和，於興慶宮修功德。 | 天宝三载（744），大秦国有僧人佶和，观星象而归向王化，望太阳（天子）而前来朝拜。皇帝下诏命僧罗含、僧普论等十七人（或读七人），与大德佶和在兴庆宫做功德。<br>〔注〕兴庆宫是玄宗的主要居所。“修功德”即举行宗教仪式、为皇家祈福。 |
| 於是天題寺牓，額戴龍書。寶裝璀翠，灼爍丹霞；睿扎宏空，騰淩激日。寵賚比南山峻極，沛澤與東海齊深。 | 于是皇帝亲题寺名匾额，匾上载着御书。宝饰璀璨青翠，灼灼如红霞；御笔气势恢宏，腾越凌空，激射日光。宠赐之厚可比南山的高峻，恩泽之广与东海一样深。<br>〔注〕“激日”，《大正藏》误录作“激曰”。 |
| 道無不可，所可可名；聖無不作，所作可述。 | 道无所不可，凡其所可者都可以称名；圣王无所不作，凡其所作都值得记述。 |

## 七、序：肃宗、代宗、德宗朝

## 八、序：大施主伊斯

| 碑文原文 | 白话译文 |
| --- | --- |
| 大施主金紫光祿大夫、同朔方節度副使、試殿中監、賜紫袈裟僧伊斯，和而好惠，聞道勤行。遠自王舍之城，聿來中夏。 | 大施主、金紫光禄大夫、同朔方节度副使、试殿中监、赐紫袈裟的僧人伊斯，性情温和而乐于施惠，闻道之后勤于践行。他从遥远的王舍之城来到中原。<br>〔注〕王舍之城：据碑下叙利亚文，即吐火罗斯坦的缚喝（Balkh，今阿富汗北部巴尔赫）。玄奘《大唐西域记》称缚喝为“小王舍城”。逐句剖析见附录三。 |
| 術高三代，藝博十全。始効節於丹庭，乃策名於王帳。 | 他的医术高过三代（世传名医），技艺广博可称“十全”。起初在朝廷效力尽忠，后来在王者军帐中委身任职。<br>〔注〕“三代”“十全”多解作医术用语：《礼记》“医不三世，不服其药”，《周礼·天官·医师》“十全为上”。 |
| 中書令汾陽郡王郭公子儀，初總戎於朔方也，肅宗俾之從邁。雖見親於臥內，不自異於行間。為公爪牙，作軍耳目。 | 中书令、汾阳郡王郭子仪公当初在朔方统领军队时，肃宗命伊斯随他出征。伊斯虽然受到亲信、得以出入卧内，却不在行伍之中自显特殊。他做郭公的爪牙，当全军的耳目。 |

| 餧者來而飯之，寒者來而衣之，病者療而起之，死者葬而安之。 | 饥饿的人来了，就给他饭吃；寒冷的人来了，就给他衣穿；生病的人，为他医治使他痊愈；死去的人，为他埋葬使他安息。<br>〔注〕参《马太福音》25:35—36。“餧”即“馁”。 |
